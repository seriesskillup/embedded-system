# Embedded System — Step-Up Series (companion code)

Runnable code for the **Embedded System Step-Up Series** by Gazi M. Ehsan.
Each book has its own folder under `Books/`.

## Books

| Book | Folder |
|---|---|
| Book 1 — *C Deep Inside for Embedded System Development* | [`Books/C Deep Inside/`](Books/C%20Deep%20Inside/) |

Build any example with a C17 compiler (or a free web IDE such as OnlineGDB):

```
gcc -std=c17 -Wall -Wextra -Wconversion main.c -o demo && ./demo
```
