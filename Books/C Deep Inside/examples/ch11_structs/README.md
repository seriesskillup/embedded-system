# Chapter 11 — Structures, Unions, Enumerations (runnable demo)

What it shows and how to run it are in the book, Chapter 11 — Structures, Unions, Enumerations *Putting it together*.
Covers: padding and alignment, a packed struct, union type-punning, endianness, and an enum constant being int-wide. Runs as-is.

```
gcc -std=c17 -Wall -Wextra -Wconversion main.c -o demo && ./demo
```
