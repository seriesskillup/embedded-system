# Chapter 13 — Bitwise Operators (runnable demo)

What it shows and how to run it are in the book, Chapter 13 — Bitwise Operators *Putting it together*.
Covers: set/clear/toggle/test a bit, field extract and insert, the precedence trap, and a signed 1-bit field. Intentionally fires two teaching warnings (-Wparentheses, -Wconversion).

```
gcc -std=c17 -Wall -Wextra -Wconversion main.c -o demo && ./demo
```
