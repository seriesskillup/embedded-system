# Chapter 15 — const & Read-only Data (runnable demo)

What it shows and how to run it are in the book, Chapter 15 — const & Read-only Data *Putting it together*.
Covers: the four const-pointer forms, const-correctness, a const table, and a const volatile status register (simulated). Runs as-is.

```
gcc -std=c17 -Wall -Wextra -Wconversion main.c -o demo && ./demo
```
