# Chapter 16 — Dynamic Memory Allocation (runnable demo)

What it shows and how to run it are in the book, Chapter 16 — Dynamic Memory Allocation *Putting it together*.
Covers: the malloc/free discipline, realloc-with-a-temporary, and a fixed-block pool with a high-water reading. malloc works on a host, so it runs as-is.

```
gcc -std=c17 -Wall -Wextra -Wconversion main.c -o demo && ./demo
```
